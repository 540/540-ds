# Design tokens

<!-- predictable:capability={"authors":["runner"],"backlog":false,"covers":["src/tokens/breakpoints.ts","src/tokens/manifest.ts"],"created":"","guidelines":[],"id":"SPEC-543","lastModified":"","lastVerified":"","proseDigest":"958a893d5a737091","relatedSpecs":[]} -->
The design tokens module (src/tokens/breakpoints.ts and src/tokens/manifest.ts) names the system's screen breakpoints and lists its tokens for the Foundations documentation pages. BREAKPOINTS is {tablet: 600, desktop: 1024}, in px; DESIGN_WIDTHS, the widths each range is designed at, is {mobile: 375, tablet: 768, desktop: 1440}; MEDIA holds, for tablet and for desktop, the media query '(min-width: <its breakpoint>px)', so tablet is '(min-width: 600px)' and desktop is '(min-width: 1024px)'. The manifest holds token names, labels and descriptions but no values: colorPrimitives is a list of groups, each with a title, a description and items naming a --540-* color primitive with its label; semanticColors is a list of groups of --color-* tokens, each item naming the --540-* primitive it takes in light and in dark, and its usage; textStyles has one entry per text style with its key, label, tokenPrefix, mobile and desktop size in px, weight and weight name, line height, letter spacing and usage, and every tokenPrefix has the four tokens <prefix>-size, <prefix>-weight, <prefix>-line-height and <prefix>-letter-spacing; effectTokens lists the --gradient-* and --filter-* tokens, each with the primitive it takes in light and in dark; spacingTokens (--space-*), paddingTokens (--padding-*), gridTokens (--grid-*), sizeTokens (--size-*) and radiusTokens (--radius-*) list the measure tokens with their label and, for some, their usage and their mobile and desktop value in px. Every token name, light alias and dark alias the manifest names is a custom property declared in the token CSS files primitives.css, semantic-color.css, semantic-typography.css or semantic-measure.css.
