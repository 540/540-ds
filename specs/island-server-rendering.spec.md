# Island server rendering

**Areas:** Runtime

The server side of the island runtime (src/runtime/server.ts and src/runtime/islands.ts) turns design-system components into static HTML that the client runtime later hydrates. registryOf collects, from the modules it is given, every export whose name starts with a capital letter and whose value is a component (a function, or an object with $$typeof), keyed by its export name; other exports are left out. ISLAND_TAG is 'ds-island' and SLOT_TAG is 'ds-slot'. renderIsland(registry, {name, props, id, slots}) throws '540-ds: component "<name>" is not registered' when the registry has no component of that name; otherwise it renders the component with its revived props to HTML, with id as the prefix of every id the component generates with useId, and wraps that HTML as <ds-island data-c="<name>" data-id="<id>" data-p="<props as JSON>">, escaping &, " and < in those attributes. revive turns encoded props back into props: an object with a string $slot becomes a Slot rendered as <ds-slot data-s="<slot id>"> holding that slot's HTML, and renderIsland throws '540-ds: slot "<slot id>" has no HTML' when its slots have no entry for it; an object with a string $el becomes an element of that HTML tag when the name starts with a lowercase letter, otherwise of the registered component of that name, with its revived p as props, and revive throws '540-ds: component "<name>" is not registered; include its island' when no such component is registered; any other array, object or plain value is revived member by member and keeps its shape. renderStatic(element, id) renders an element the same way, with id as the prefix of its generated ids, without the island wrapper. renderToString(element, {identifierPrefix}) renders it with identifierPrefix as that prefix, or none when it is absent, and renderToStaticMarkup is the same function.
