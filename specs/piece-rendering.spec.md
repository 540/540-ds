# Piece rendering

The piece renderer (scripts/render: index.mjs, core.mjs, parse.mjs, rules.mjs and spelling.mjs) turns a talk written with <rev-…> tags into one self-contained HTML page. renderTalk(source, {pieces, baseDir, lang, origin}) throws 'renderTalk needs the pieces folder' when pieces is not given; otherwise it reads pieces/manifest.json and returns {html, version, components, islands, scripts, warnings}, where version is the manifest's version, islands lists the island components the page hydrates and scripts says whether the page carries any script. The page has <html lang> set to lang, else to the talk's own language, else 'es'; its head has <meta name="540-ds-version" content="<version>"> and the talk's <title>; the component CSS is inlined in one <style> with every font of manifest.base.fonts embedded as a data:font/woff2;base64 URL, and every image is embedded as a base64 data URL. A talk made only of static components gives a page with no <script> and no <ds-island>; a talk with islands such as Deck, Steps and Statements gives a page that ships their scripts inline and wraps each island in <ds-island>; inside Steps, a Step's content that is itself a component or SVG is passed as encoded props ({$el, p}) and plain copy as a {$slot}. A talk may also be a page for the browser runtime, its tags inside one <script type="text/rev">: it renders to the same HTML as the plain tags, its data-lang gives the language unless lang is given, errors point to the line and column of the file, and the renderer throws a TagError when there is more than one such block ('only one <script type="text/rev"> per page') or content outside it ('the whole talk goes inside it'). A syntax problem is not collected: parse (parse.mjs) throws at the first one it meets (an unknown entity, a comment or a tag never closed, a malformed or repeated attribute, a closing tag that does not match the open one), and prepareTalk (core.mjs) throws it alone as a TagError '<origin> has 1 problem:'. Once the document parses, every problem prepareTalk finds is collected and thrown together as one TagError '<origin> has <n> problem(s):' with one line per problem: an unknown tag, with the nearest known tag as 'did you mean'; a value outside a prop's options ('<prop> is one of …, not "<value>"'); an attribute the component does not take; plain HTML other than the phrasing tags strong, em, b, i, code, small, sub, sup, br and a (with href); a field a JSON prop does not have; a component that cannot be used from a tag; a missing required prop; content in a component that takes none; a remote image ('points to a remote image') or an image file that does not exist ('image not found'); and, inside a Schema drawing (rev-schema and rev-schema-layer), a class outside the Schema vocabulary, an SVG attribute outside the allowed list such as fill, or a <rev-…> component. A photo of the image library is written biblioteca:<id>: it is embedded from the pieces folder, an id not in manifest.images is a problem that suggests the nearest id, and the same library photo used more than once gives a warning 'biblioteca:<id> is used <n> times'. The renderer also warns, without failing: when a static wrapper cuts a component off its Steps; when one stop shape passes 30 % of the content stops ('<k> of <n> content stops (<p> %)', naming those stops), only when the deck has at least 5 content stops (MIN_STOPS_FOR_SHARE); when two stops in a row have the same shape whatever their copy ('two stops in a row with the same shape'); both checks (checkVariety) look only at the direct children of <rev-deck>, and the content stops are those children leaving out the frame stops rev-cover, rev-block-title and rev-closing; about a big photo with a sentence under it; and when the text beside a photo is aligned to the start. In a Spanish talk (the default) checkSpelling gives one warning per word that neither the Spanish nor the English dictionary nor the 540 word list (WORDS_FILE, render/palabras-540.txt) knows, quoting the word, saying how many times it appears when more than once and adding up to three Spanish suggestions; capitalized words, acronyms, code-like words and words shorter than three letters are skipped, as is the copy inside <code>; a talk in another language is not spell-checked.
