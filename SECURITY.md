# Seguridad

## Cómo avisar de un problema

No abras un issue público para un problema de seguridad.

1. Usa el aviso privado de GitHub: pestaña **Security** de este repositorio, botón **Report a vulnerability**.
2. Si no puedes usar GitHub, escribe a hola@540deg.com con el asunto «Seguridad 540-ds».

Cuenta qué encontraste, cómo se reproduce y qué versión del paquete usas. Respondemos en un plazo de cinco días laborables.

## Qué cubre

- El paquete `@540deg/ds` publicado en npm.
- El servidor MCP público del sistema de diseño.
- El catálogo publicado en ds.540deg.com.

## Versiones con soporte

Solo la última versión publicada en npm recibe correcciones.
